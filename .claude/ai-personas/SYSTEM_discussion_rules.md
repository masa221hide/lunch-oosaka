# 6AI討議システム ルール定義

## 討議の基本原則

### 1. 繰り返し討議の原則
- 1ラウンドで結論を出すことを禁止する
- AI-1（司会）が「全員合意」を確認するまで追加ラウンドを続ける
- 合意の目安：「矛盾なし」「実行可能」「前提条件が満たされている」の3点が揃うこと

### 2. 前提条件確認の原則（最優先）
AI-1は以下が不明な場合、議論開始前にユーザーへ確認を求める：
- 対象者プロフィール（年齢・経験・スキル・業界歴等）
- 制約条件（予算・期間・地理・組織規模等）
- 最終ゴール（何を持って成功とするか）
- リスク許容度（失敗した場合の影響範囲）

### 3. 発言順序の原則
```
ラウンド開始
  └─ AI-0：現状データ提示（必ず最初）
  └─ AI-1：論点整理・議題設定
  └─ AI-2：確実策の提案
  └─ AI-3：矛盾検証
  └─ AI-4：革新的代替案
  └─ AI-5：具体的実装案
  └─ AI-1：整理・次ラウンド判断 or 最終結論
```

### 4. 合意判定の原則
AI-1が最終結論を出す前に確認する項目：
- [ ] AI-3が「矛盾なし」を宣言した
- [ ] AI-5が「実行可能」を宣言した
- [ ] AI-2が「リスクが許容範囲内」を宣言した
- [ ] AI-0が「前提データと整合している」を確認した
- [ ] 4点すべてクリアした場合のみ最終結論を出力する

### 5. ユーザーへの確認フォーマット
```
【AI-1より確認事項】
以下の情報が不足しており、最適な回答が出せません。
ご回答をお願いします：

Q1：[質問内容]
Q2：[質問内容]
Q3：[質問内容]

ご回答後、討議を再開します。
```
